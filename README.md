> **Durum:** Yayımlanmamış ön-baskı (preprint, v1, 2025). Hakem denetiminden geçmemiştir.

Serinin ilk halkası: sicim titreşimi durduğunda ($\omega = 0$) zaman ve entropinin anlamını yitirdiği,
kara deliklerin enerji ve zamanın bittiği, mükemmel düzenin yeniden sağlandığı geçitler olduğu önermesi.
Makale Türkçe + İngilizce mevcuttur.
